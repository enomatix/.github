# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for the affected repository whenever it is available.

If private vulnerability reporting is unavailable, email:

security@enomatix.com

Include:

- The affected repository or service
- A clear description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested remediation
- Your preferred contact details

## Response process

We will:

- Acknowledge valid reports as soon as reasonably possible
- Investigate the issue
- Keep the reporter informed where appropriate
- Coordinate remediation and disclosure responsibly

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
